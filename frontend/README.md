# ✨ PookiePy

An interactive Python learning platform that visualizes programming concepts in a beginner-friendly and aesthetic way.

## 🌸 Features

- Interactive UI
- Variables visualizer
- Cute beginner-friendly design
- Real-time memory box simulation
- React-based frontend

---

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- CSS

---

## 🚀 Run Locally

```bash
cd frontend
npm install
npm run dev
```

---

## 💖 Vision

PookiePy aims to make Python learning:
- visual,
- interactive,
- fun,
- and beginner friendly.
